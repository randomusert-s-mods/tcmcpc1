# tincraft modpack core 1
Welcome to the official modpack for tincraft.

This mod is a core mod providing the Custom progression, items and blocks for modpack.

# Contributing
Hi. We're looking for contributors. If you have experience in minecraft 1.21.1 neoforge mod developement, please contact me trough issue.

However if you don't have experience in mod development, but you still want to contribute, you can write docs for the pack.
